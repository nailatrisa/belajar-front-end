# Belajar Front-End

Proyek ini berisi latihan HTML, CSS, dan JavaScript yang disusun berdasarkan hari pembelajaran.

## Struktur Proyek

- `mencoba.html` - halaman utama percobaan di root.
- `html/` - folder utama berisi kumpulan file latihan HTML.
- `html/css/` - folder berisi file CSS untuk styling latihan.
- `html/css/js/` - folder berisi file JavaScript untuk interaksi dan latihan dinamis.

## Isi Folder

- `html/` berisi file `hari1.html`, `hari2.html`, ..., `hari26.html`, dan beberapa file latihan tambahan.
- `html/css/` berisi file CSS yang diberi nama sesuai hari (`hari21.style.css` sampai `hari50.style.css`).
- `html/css/js/` berisi file JavaScript yang diberi nama sesuai hari (`hari51.js` sampai `hari80.js`).

## Cara Menggunakan

1. Buka file HTML dari folder `html/` di peramban web.
2. Pastikan file CSS yang sesuai sudah dihubungkan di dalam file HTML.
3. Jika ada interaksi JavaScript, pastikan file JS yang sesuai sudah dimuat di dalam file HTML.

## Tujuan

Proyek ini digunakan untuk:

- Latihan dasar struktur HTML.
- Eksperimen dengan styling CSS.
- Belajar konsep JavaScript untuk web.

## Tips

- Gunakan browser modern seperti Chrome, Firefox, atau Edge.
- Jalankan file HTML langsung dari folder lokal, atau gunakan server lokal sederhana jika diperlukan.
- Periksa tautan `link` dan `script` di setiap file HTML agar CSS dan JS terhubung dengan benar.
